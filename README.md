# C Language Programs

This repository contains a collection of C programs created while learning and practicing the fundamentals of C programming.

## Programs Included

- *Pattern Matching* – Implements pattern matching in C.
- *Sum* – Calculates the sum of numbers.
- *Circular Queue* – Implements a circular queue with enqueue, dequeue, and display operations.
- *Factorial* – Calculates the factorial of a number.
- *Fibonacci* – Generates the Fibonacci sequence.
- *Hot or Cold* – A simple hot or cold program.
- *Pointer* – Demonstrates the use of pointers in C.
- *Quadratic Equation* – Solves a quadratic equation.
- *String* – Demonstrates string operations in C.
- *Swap* – Swaps two numbers.

## Language Used

- C

## Purpose

This repository is mainly for practicing C programming concepts such as:

- Variables and data types
- Loops and conditional statements
- Functions
- Arrays and strings
- Pointers
- Data structures
- Basic algorithms
